# LoadSentry implementation rules

Before implementation, status changes or review, read docs/IMPLEMENTER_PROTOCOL.md and docs/EXECUTION_PLAN.md, then the issue's stable task contract in planning/backlog.json. Activation and portfolio WIP capacity are mandatory gates; this repository is currently queued.

When data, weights, evaluation, architecture or scope changes, update the corresponding decision and rights records before continuing. At review, attach reproducible acceptance evidence and preserve the distinction between synthetic benchmarks, public real data and customer validation.
